# Product Decisions

- Главный пользователь MVP: владелец автомобиля.
- Редактирование старых записей разрешено только с audit log.
- Удаление записей — мягкое.
- Владелец видит полный VIN в своём кабинете.
- Публичный пользователь видит маскированный VIN.
- Стоимость показывается публично только по выбору владельца.
- Публичная ссылка действует 1 час.
- Пакетный ремонт должен храниться как ремонтный визит с позициями.
