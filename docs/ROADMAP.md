# Roadmap

## Завершено в 0.24.1

- GitHub назначен каноническим источником исходного кода.
- Добавлен обязательный repository integrity gate.
- Добавлена проверка согласованности VERSION и README.

## Следующий приоритет

- Довести основной CI до зелёного состояния.
- Подтвердить наличие полного дерева `app`, `alembic`, `scripts`, `tests` и `docs`.
- После зелёного CI перейти к storage quotas и административной модели доступа.
