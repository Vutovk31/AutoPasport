# Risk Log

## R-024 — Неполная загрузка исходников

**Статус:** контролируется автоматически.

Риск: ручная загрузка может пропустить вложенные каталоги, при этом корневые release-файлы создают ложное впечатление готового репозитория.

Контроль: workflow `Repository integrity` завершает проверку с ошибкой при отсутствии обязательных компонентов.

Остаточный риск: workflow подтверждает структуру, но функциональную работоспособность подтверждает только основной CI и pytest.
