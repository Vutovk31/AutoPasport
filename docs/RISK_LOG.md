# Risk Log

## R-024 — Неполная загрузка исходников

**Статус:** контролируется автоматически.

Контроль: workflow `Repository integrity` завершает проверку с ошибкой при отсутствии обязательных компонентов.

## R-025 — Небезопасная production-конфигурация

**Статус:** снижен startup gate.

Риск: приложение может быть запущено в production с HTTP, небезопасной cookie, коротким стандартным admin token, относительной SQLite-базой или общим каталогом для storage и backup.

Контроль: `scripts/check_config.py` вызывается Docker entrypoint до миграций. При `APP_ENV=production` обнаруженная небезопасная настройка завершает запуск с кодом ошибки.

Остаточный риск: проверка конфигурации не заменяет внешний secret manager, TLS termination, ограничение сетевого доступа и ротацию секретов.

## R-026 — Утечка приватных данных через публичный GitHub

**Статус:** снижен CI privacy gate.

Риск: случайный commit `.env`, SQLite-базы, credential-файла, токена, приватного ключа или реального VIN делает данные доступными в истории публичного репозитория.

Контроль: `scripts/check_repository_privacy.py` проверяет обязательную структуру, запрещённые файлы и расширения, известные форматы секретов и возможные 17-значные VIN до миграций и тестов.

Остаточный риск: pattern scan не гарантирует обнаружение всех видов секретов и не удаляет данные из уже опубликованной Git history; при реальной утечке необходимы немедленная ротация и очистка истории.

## R-027 — Неограниченный рост storage владельца

**Статус:** снижен owner-wide quota.

Риск: владелец может загрузить неограниченное число документов через события и сервисные визиты, исчерпав диск приложения или ухудшив время backup/restore.

Контроль: SQLAlchemy listener проверяет количество и суммарный объём активных вложений по всем автомобилям владельца до вставки Attachment. Лимиты задаются `MAX_OWNER_ATTACHMENTS` и `MAX_OWNER_STORAGE_BYTES`; превышение возвращает структурированные HTTP 409/413 ошибки.

Остаточный риск: физический storage остаётся локальным, отсутствуют резервирование дискового пространства, per-plan quotas и UI текущего использования.
